# 前端 AI 开发约定

适用于 `frontend/`。先读取并遵守 [根 AGENTS](../AGENTS.md)，本文件只规定前端差异。

## 依据与边界

- 阅读 [前端 README](README.md)、[架构](../ARCHITECTURE.md)、[产品](../docs/PRODUCT.md)、[契约](../docs/CONTRACTS.md)。
- 使用已经确定的 React 技术栈；Node 固定 24 LTS。具体依赖版本验证后锁定，不混用包管理器和锁文件。
- 单页应用通过同源 `/api/v1` 调用后端。前端不直连 PostgreSQL、千问或和风天气，不接触服务私钥。
- API 字段使用契约命名。前端类型从后端 OpenAPI 生成后不得手改；Zod 负责运行时边界校验，生成策略由初始化阶段落实。

## 文件与依赖边界

- 执行根 AGENTS 的文件规模规则。`features/wardrobe/` 等是业务目录，内部按实际需要拆成页面、组件、hooks、API 和 schema；不提前创建空壳文件。
- 页面文件负责页面布局和组合；不同时实现 HTTP/SSE 客户端、完整表单校验及全部子组件。
- hooks 负责查询/更新与状态组合；API 文件负责网络和边界校验；组件负责明确的交互或展示。不要把一个超长页面机械搬进一个超长 hook。
- `app` 组合 feature；feature 依赖公共 UI、lib 和生成类型。公共层不反向依赖 feature，feature 不跨目录深层导入其他 feature 私有实现。
- 业务组件先留在对应 feature，出现稳定复用需求再提升为共享组件；不是所有组件都要放进全局 `components/`。
- `lib` 按 HTTP、SSE 等职责命名，不使用不断增长的 `utils.ts`、`helpers.ts` 接收所有逻辑。测试与行为相邻，跨功能端到端测试独立组织。

## 状态和交互

- TanStack Query 管后端数据；React Hook Form 管表单草稿；本地 state/reducer 管临时 UI 与流式呈现。不得多处复制权威衣橱数据。
- 所有生成/修改任务由明确的用户事件触发。禁止在 mount、Query 自动重取、页面刷新或 SSE 重连时创建付费任务。
- 按钮与聊天使用同一套锁定条件、会话 ID 和目标搭配版本，禁止两个入口行为分叉。
- 条件、选中方案与锁定写入会话版本；首页通过 current 会话接口恢复。首次无会话不能为了填充首页自动调用模型。
- 发请求前持久保存操作幂等键，传输失败重发复用；restore 成功的 data_epoch 变化必须清空旧 Query 缓存、事件游标和待发操作。
- 表格记录人工编辑字段，晚到 AI 更新不能覆盖手工输入；只替换模式展示目标项，并保持其他单品。
- 只把完整且通过 Zod 校验的事件用于状态更新。网络 chunk 不等于 SSE 事件；半段 JSON 不渲染成最终搭配。
- 按任务 ID 和事件序号去重，恢复已保存任务；停止订阅不等于取消后台任务。
- 修改衣服状态后刷新相关查询。展示旧搭配与重新使用时的当前可用性是两个概念。
- 不把未知属性、天气获取失败、未拥有建议或 Fake Provider 结果展示成确定事实。

## UI 设计维护

- 本项目已本地安装 `ui-ux-pro-max`，UI 工作读取项目 `.agents/skills/ui-ux-pro-max/SKILL.md`；来源、恢复安装信息和已采用设计见 [界面设计](../docs/design/UI.md)。技能建议不能覆盖产品和接口约束。

## 移动端与导入

- 核心目标：安卓 Chrome、iOS 18 Safari。适配安全区、软键盘、触摸操作及屏幕旋转。
- 只采用同一套 Base UI 底层的 shadcn 组件。弹层、表单和按钮在 `components/ui` 统一封装。
- 衣橱页重效率；搭配和收藏页重视觉。桌面批量审核使用表格；手机保留逐行审核语义，显示关键列并展开其余字段。
- Excel 导入与照片上传共用预览编辑组件；前端扩展名检查不能替代后端文件解码校验。
- 定位失败立即提供手动城市选择，不反复弹授权，不阻断穿搭。更换城市要更新显示的天气来源和时间。
- 完整覆盖 loading、empty、error、success、任务中断及可重试状态；不使用只在截图里好看的静态假按钮。

## 验证

- 完成相关改动后运行实际存在的类型检查、格式/静态检查、组件或端到端测试。
- 优先测试：刷新不生成、锁定调整、逐行导入、断线恢复、未知字段、图片降级。
- MSW 用于确定性模拟；真实手机体验尤其定位、文件选择与 HEIC 行为需真机验证，Playwright 模拟不等同于完成真机验证。
- 运行方式写入 [README](README.md)，实现证据写入 [开发记录](../docs/DEVELOPMENT.md)。
