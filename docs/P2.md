# P2 · 衣橱与导入交付

日期：2026-10-26。工程闭环已实现；真实手机照片、Excel 客户端保存样例和千问识别的外部验收仍待补齐。不会把合成样例或 Fake 结果当成真实服务验收。

## 可操作入口

- `/wardrobe`：单品网格，名称、品类、季节、场合、状态和自定义标签筛选；详情编辑、原件下载、原图/去背景切换、软删除。
- `/imports`：照片批量上传或下载 v1 模板并上传 Excel；保留最近批次入口。
- `/imports/:id`：共用审核表，桌面表格、手机逐行卡片；修改草稿、选择有效行、逐行/批量确认、移除、失败步骤重试。
- 首次初始化播种一件标记为示例的上装；删除后不会在重启或迁移时重新播种。

照片最多 20 张、单张 20 MiB、合计 200 MiB；Excel 最多 50 MiB、100 行。图片加品类必填，其他属性可空，新衣服可穿。Excel 标签按原值保留，不自动识别；照片识别目前为显式 Fake（只预填上装）或 disabled（人工补充），真实千问适配未实现。

## 持久化与并发约束

新增迁移 `ea067667e0f3`，接在 `0001_foundation` 后：媒体、衣服、标签、批次、审核行、操作回执，以及 SystemState 的示例播种标记。没有重写 P1 迁移。

- Garment 属性通过统一 Pydantic/词表校验后写入 JSONB。标签关系在 `custom_tag_ids` 中保存 UUID，API 检查存在性；删除标签移除当前衣服/未确认草稿的引用并递增版本。尚未建立独立 GarmentTag 表，后续多人或复杂检索时再迁移，不能复制两套权威关系。
- 上传幂等回执绑定文件内容 SHA-256 和文件名；同键不同内容返回冲突。客户端在 POST 前保存操作键，网络失败重发复用。
- 确认采用同一事务内逐行保存点、行锁、expected_version 和 confirmed_garment_id；有效行入库、错误和版本冲突行独立返回。不同操作键并发确认同一行也只能创建一件衣服。
- 人工修改字段（含显式清空）写入 touched_fields；晚到识别只合并仍为空且未人工触碰的字段。确认后不改衣服属性。前端编辑器保留打开时版本及未保存输入，后台轮询不覆盖草稿；冲突需读取新版本后重新保存。
- 删除单品是软删除；原图、展示图、去背景图保留。当前没有自动垃圾回收，孤立文件也保守保留；磁盘清理和备份恢复在后续阶段处理。

## 文件处理与安全边界

原件存入 `wardrobe_media_data` 命名卷，由应用生成路径，文件名不参与磁盘路径拼接。图片解码、Excel 解析和去背景在独立 worker 执行；上传保存通过线程池，不在 API 事件循环做模型计算。

- Pillow 12.3.0 + pillow-heif 1.8.1：检查真实格式、单帧、64 MP 限制，按 EXIF 方向转正；最长边 1600，生成去除元数据的 PNG。保留原始 HEIC/其他照片不变，“原图视图”为标准衍生图，原件通过下载取得。
- rembg 2.0.86 + ONNX Runtime 1.31.0：本地 CPU `u2netp` 去背景；构建镜像时下载并由库校验模型，运行时无需再下载。模型目录给非 root 运行用户只读权限。默认图片处理并发为 1。
- 构建首次需要访问 Python 包仓库和 rembg 官方 GitHub 模型发布；本地直接启动 worker 时，首次去背景也可能下载到 rembg 缓存。Compose 镜像已内置权重。
- openpyxl 3.1.5 + defusedxml：按绘图锚点而非 ZIP 顺序对应行。模板采用浮动嵌入图，每行一图，图片需完整落在该行。跨行、重复图、缺图和非法字段都有错误。
- 拒绝宏、外链、现代单元格图片/richData、公式和不符模板；限制 ZIP 条目、解压总量、压缩比及工作表范围。结构性图片/公式错误需修正源 Excel 后重新导入，属性错误可在页面修正。
- Nginx 与 API 限制请求体 210 MiB（包含 multipart 开销）；单文件/总文件另按业务上限校验。HTTP 仍用于可信本机/局域网，当前没有多用户认证。

## 任务与错误恢复

P2 复用 P1 的 Job 领取、心跳、租约隔离、事件账本和取消接口；不为图片处理硬塞 LangGraph。P1 Checkpointer 保留，正式搭配图在 P4 实现。

- `import_photos` / `import_excel` 是父任务；步骤重试产生 `media_convert` / `media_cutout` / `garment_recognize` 新任务。
- 每个步骤独立保存结果；不在耗时计算中持有写事务，提交时检查租约和行是否已移除。父任务 succeeded 表示处理流程结束，审核结果和失败步骤仍须看逐行状态。
- 父任务失败/中断/取消会映射尚未结束步骤的状态。重试需用户点击，不因刷新重跑；已确认/移除行禁止重试，确认前可以选择使用已有原图或重试失败步骤。
- 转换失败且没有展示图不能确认；识别失败可手动填；去背景失败可用原图。已确认衣服不会因后台去背景完成而自动换图，用户可在详情主动切换。
- Excel 解析本身失败时重新上传修正文件；只处理未确认行的步骤重试。原批次已确认行保持不变，重新导入新文件视为新批次，不跨批次自动去重。
- 当前审核页通过只读轮询恢复，不发隐式 POST；Job SSE 接口仍可读取步骤进度。
