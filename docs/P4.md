# P4 · Agent 搭配闭环

日期：2026-10-26。实现正式会话、最多三套搭配、锁定/指定项替换/聊天调整、不可变快照、SSE 恢复和千问适配。默认运行显式 Fake；真实千问已完成一次生成/指定替换验收，质量限制见[真实验收](history/2026-10-27-qwen-outfits.md)，和风账号仍待验。验证记录见 [开发记录](history/2026-10-26-p4.md)。

## 使用与边界

- 首页填写条件，点击“生成搭配”才保存正式会话条件并提交生成任务。“保存并核对条件”仍仅保存浏览器草稿。未选城市时可手动填天气，0℃有效。正式条件仅在结果快照日期和当前城市匹配时回填，避免把旧手动天气带入新日期/城市；浏览器草稿仍按日期/城市/会话隔离。
- 选择方案、锁定、条件和当前任务保存在数据库；首页 GET 当前会话，`/outfits/:sessionId` 可在另一浏览器恢复。刷新、轮询、重连不创建生成。
- 每个会话只有一个活动任务。操作带版本和幂等键；网络结果不明时可重发同一操作，刷新不自动重发。生成前的 PATCH/创建和后续生成按步骤持久保存操作键。
- 默认选中新生成第一套；调整只替换选中方案，其余候选保持。0 套或澄清保留已有结果。新建会话不生成。
- “只替换此项”保持全部非目标项，包括没有锁定的项和未拥有建议；“重搭未锁定部分”才扩大范围。锁定失效时拒绝新请求并保留旧结果，用户可解锁、恢复衣服或修改目标。
- 聊天发送属于显式调整，使用同一约束校验。指代不明返回澄清；Fake 只识别有限中文品类/重搭表达，不能代表真实语言理解。未发送聊天草稿按会话存于本浏览器。
- 单品卡片使用不可变图片引用，展示理由、未满足条件、来源及天气。未拥有建议仅文字，无购物链接。旧衣服删除或修改不破坏快照。
- 历史列表、收藏、日历、删除历史及完整备份恢复仍属于 P5。本阶段提供 revision 详情和复用会话 API，不把尚未开放的历史页面称为完成。

## 后端与数据

追加 `0004_outfits`：outfit_sessions、outfit_revisions、outfit_messages、outfit_images、outfit_model_calls；profiles 增加 current_session_id。旧迁移不重写。图片快照记录原 MediaAsset 外键和当时不可变存储键，通过 `/outfit-images/{id}` 返回；不复制图片字节，也不依赖衣服当前 display_variant。

- LangGraph `prepare → generate → commit`，`thread_id=outfit:{session_id}`。图状态仅保存 Job ID/租约；上下文、响应和提交标记在业务数据库。
- 启动时读取最新偏好、标签、真实可用衣服与默认城市。本次显式风格覆盖长期风格；未知属性保留未知，已知标签不匹配和保暖未知会明确提示。天气快照区分 manual/qweather。
- 当前候选上限 500 件；超限明确返回错误，不悄悄截断。示例不参与真实搭配。空衣橱不调用模型，返回 no_match 和上传提示。
- 手动天气按本次显式生成形成快照。自动天气必须有有效今日实况，过期/失败要求手动填写；提交时再次检查日期和到期时间。
- 后端独立校验真实 ID、当前可用性、锁定、目标、非目标保持、数量和组合差异；模型返回不合法时最多修正一次。提交前锁定相关衣服并重查版本及状态，中途修改则拒绝新结果。
- 快照、会话更新、助手消息、Job 成功与 result/status 事件在同一事务提交；`(run_id, position)` 唯一。提交后 Checkpointer 丢失可从业务事实恢复，不能重复创建 revision。
- 每个模型步骤按 `(job_id, step, attempt)` 持久记录 sent/received/invalid。已保存响应重放复用；sent 但无可靠响应则 interrupted，不自动重发。明确重试创建新 Job，重新验证当前会话和上下文，可能再次计费。
- 最多 12 图步、4 次模型调用；实际生成最多两次，聊天解析另外一次；单次总时限 120 秒、上下文准备后的任务预算 300 秒。网络没有自动重试，429/5xx 失败也不偷偷重发。
- 复用既有任务队列、租约、取消、事件游标与只读轮询。取消先到则不提交结果，成功先到则取消返回已成功；过期租约拒绝迟到提交。Checkpointer 不是任务队列或恰好一次保证。

## 接口

新增 API schema 和前端类型由 OpenAPI 生成：

- `POST /outfit-sessions`：requirements 和可选 base_revision_id；201。复用只预填，返回失效衣服，不隐式锁定或生成。
- `GET /outfit-sessions/current`、`GET /outfit-sessions/{id}`：会话及候选完整快照、最近 30 条消息；无当前会话为 null。
- `PATCH /outfit-sessions/{id}`：expected_version、requirements、selected_revision_id、locked_garment_ids；需幂等键。切换方案仅保留共有且有效锁定，返回 removed_lock_ids。
- `POST /outfit-sessions/{id}/generate`：expected_version；202 JobAccepted。
- `POST /outfit-sessions/{id}/adjust`：expected_version、base_revision_id、scope、target_item_ids、message。scope 为 replace_items/rebuild_unlocked/chat；chat 解析为同一领域操作或澄清。
- `GET /outfit-sessions/{id}/messages`：limit 1–100（默认 20）、UUID cursor，倒序分页。
- `GET /outfit-revisions/{id}`、`GET /outfit-images/{id}`：不可变版本与图片。
- `/jobs/{id}`、`/events`、`/cancel`、`/retry` 复用 P1 通用接口；搭配结果为 session_id、revision_ids、outcome、unmet_requirements、question。

## 千问配置

在本地 `.env` 设置（不提交凭据）：

```text
PROVIDER_MODE=qwen
QWEN_BASE_URL=从百炼控制台复制地域对应的 HTTPS compatible-mode/v1 地址
QWEN_API_KEY=该地域对应的 API Key
```

然后执行根 README 的 Compose 构建启动命令。模型固定 `qwen3-vl-plus`；地址不擅自猜测账户地域。配置完整只表示 configured，实际权限/额度/效果需真实账号测试。生产适配通过 HTTPX 调用兼容接口，关闭 thinking，使用 JSON Object 输出并经 Pydantic/领域二次校验，不假定原生 JSON Schema 严格保证。

2026-10-27 起新任务记录 `outfits-v4`，事实说明改由后端生成。模型只选组合和受限审美方向；`reason`、`message`、`unmet_requirements` 的模型自由文本不作为展示依据。新快照的 `reason` 包含“事实说明”和可选“审美建议（主观尝试）”两部分，前者按最终单品快照逐项列出颜色、场合、风格、季节、材质、厚薄、保暖及未知值；后者仅由 `color_echo/color_contrast/simple_palette` 枚举渲染固定建议，不能夹带属性断言。名称、偏好、天气和批次请求不推导单品事实。自由文本需求仍不能保证已满足，版型/舒适性/精确适温/批次明确未采集。

未满足条件由既有后端规则重新核对，模型提供的列表丢弃；助手完成/无结果/澄清消息使用后端模板。新增未拥有建议仅按有效品类显示“可考虑补充，具体属性待确认”，不采用模型的材质、保暖等描述；局部替换保留的旧建议快照不改写。原始模型响应继续留在调用账本，新增快照记录 `explanation_version=facts-v1`。公开字段结构和数据库结构不变，历史原文保持原样。

未发送的旧提示版本真实任务在调用前拒绝，要求显式新任务重试；已有响应优先复用，未提交响应经新渲染规则提交，不追加调用。每任务最多两次生成调用和原有超时预算不变。v3 真实解释失败见[v3验收](history/2026-10-27-outfit-v3-acceptance.md)，v4 实现与离线验证见[事实说明修复](history/2026-10-27-outfit-facts.md)。[v4真实复验](history/2026-10-27-outfit-v4-acceptance.md)已用1次调用通过本轮事实说明、审美标识、刷新和历史核对；不代表整体准确率。

当前搭配按已审核结构化衣服属性作输入，不额外上传衣服照片；未知属性不靠模型猜测。照片识别已由 P6 独立接入，须另设 RECOGNITION_MODE=qwen；详见 [P6 识别](P6-recognition.md)。无凭据用 `PROVIDER_MODE=fake`；禁用用 disabled，真实服务失败绝不切 Fake。

官方依据：[百炼结构化输出](https://help.aliyun.com/en/model-studio/qwen-structured-output)。此次只核对文档并模拟 HTTP 响应，没有使用真实凭据或产生真实模型费用。
