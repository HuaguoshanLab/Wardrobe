## 字段和边界

- 只有图片和品类必填。可穿状态保持原默认；状况和合身默认未知，不自动标记完好/合身。
- 子类以名称进入草稿，按品类精确解析已有稳定子类；用户确认入库时才创建新的自定义子类。停用或不兼容需明确修正，不静默重新启用。名称不用于自动创造四季需求。
- 获得来源、日期、人民币金额、位置、备注只由表格或人工提供。日期不是录入时间，未知金额不是 0 元。收纳不等于不可穿。
- 新字段存入现有导入 JSON 草稿；正式入库拆分到 lifecycle/subtype_id，基础 Attributes 不混入新字段。不自动建立维修、退出或保留决定，不生成不存在的过去事件。
- AI 只增加可见子类预填；明显破损作为 uncertainties 说明，仍由人确认状况。禁止推断实际合身、获得资料、收纳、材质/厚度/保暖，以及保留/丢弃决定。
- Excel 已填写与人工修改优先；后台晚到只补空白且未人工触及字段。明确清空也受保护。确认后不得再合并。
- 四季目标、补充计划和换季会话不属于单件导入资料，仍独立维护。
