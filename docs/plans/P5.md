## 1. 历史、收藏与实际穿着闭环

先完成此闭环并验证，再扩大到备份恢复。保留 0001–0004 迁移、全部不可变版本、图片引用和调用账本，追加迁移。

- 在 `backend/app/db/` 增加历史可变元信息、收藏、穿着记录；内容快照仍以 `OutfitRevision` 为唯一事实来源。历史隐藏不删除 revision/outfit_images，不改快照正文。
- 历史列表使用创建时间/UUID 游标分页；收藏固定 revision，重复收藏去重，名称和版本独立。穿着记录允许同日多套，日期按归属时区验证，拒绝未来日期。
- 删除历史须处理所有引用该版本的会话，而不只是原生成会话：P4 的 `create_session(base_revision_id=...)` 可以让另一会话选中同一版本。锁定相关会话，遇到活动任务返回可解释冲突；清空对应选择和锁定、移除候选引用、递增会话版本，保留收藏和穿着记录。不能让下一次轮询重新选中隐藏版本。
- 复用调用既有会话创建接口，只预填并显示失效单品；不得触发 generate。核对旧标签及旧日期天气的处理，避免复用旧条件后无法纠正。
- 在 `/collections`、`/calendar` 替换现有占位页面，提供详情、命名、取消收藏、穿着补记/编辑/删除。生成结果入口可显式收藏和记录穿着。
- 创建与修改复用操作回执和并发版本；前端发出请求前持久保存键及负载，网络失败和刷新后显式重发原操作。同步 schema、OpenAPI、生成类型和运行时校验。

验证：A-14/A-15/A-16/A-34；隐藏已收藏/已穿着/跨会话复用版本；有任务时删除竞争；重复提交和版本冲突；原衣服修改/删除后旧属性和图片字节不变；刷新、收藏、复用及记录穿着均不新增模型调用。

## 2. 全局维护屏障与备份导出

实际待改入口：`backend/app/api/system.py` 目前固定 `maintenance=False`；`backend/app/jobs/worker.py` 持续 sweep/claim/run；`backend/app/agent/checkpoints.py` 每次运行建立独立连接。当前没有全局写入屏障。

- 屏障必须跨 API/worker 进程，覆盖领取、整个执行生命周期及最终 Checkpointer 写入，不能只检查 Job 已终态。P4 故障测试证明业务提交可能早于检查点完成。
- 排查全部写入路径，包括 GET 引发的天气缓存/城市目录/默认 profile 写入、导入媒体文件写入及事件清理；不能仅按 POST/PATCH/DELETE 方法判断业务写入。
- 维护控制使用独立持久目录及原子状态文件；控制任务不能依赖被暂停的普通 worker。为等待静止设置上限；无法静止则失败并可靠解除屏障，不发布备份。
- 静止后导出业务和 checkpoints schema，枚举媒体及导入原件引用，逐文件校验后原子发布包。清单字段、排除项及顺序按 ARCHITECTURE；不递归打包整个数据目录。
- 导出任务接入既有 Job 查询和 SSE 结果类型；下载路径由服务端资源 ID 解析。失败包不可下载为成功备份。

验证：A-27 导出部分、A-30 导出部分；并发上传/领取/天气缓存写入；业务已提交但检查点未完成；超时/磁盘失败/缺图；清单、文件大小、SHA-256；包内无环境文件、凭据、模型缓存或旧备份。

## 3. 隔离验证、确认覆盖与成对回退

- 上传验证在隔离目录及隔离 PostgreSQL 数据库完成，不对运行库试导入。限制包大小和条目数，拒绝路径穿越、符号链接、重复路径、损坏文件及不兼容版本；避免把上传包中的 SQL 当作可信应用代码执行。
- 支持版本需精确列出格式、应用、Alembic 和 Checkpointer 适配器版本；不兼容明确拒绝，不猜测升级路径。
- 确认令牌绑定完整包哈希、目标 data_epoch 和失效时间；覆盖前重新检查。先建立当前数据库和媒体的成对恢复点，再按架构顺序隔离连接并切换。
- 恢复 ID、幂等回执、进度、事件及回退阶段均在目标库外持久保存。进程重启后按持久阶段恢复控制，不依赖旧业务 Job 表，不盲目重复覆盖。
- 校验成功后更新 data_epoch，并将备份内 queued/running/cancel_requested 任务转为 interrupted、废弃旧租约。会话保留历史，继续操作必须显式发起；不能自动重放模型请求。
- 前端设置页提供验证摘要和明确的覆盖确认；等待维护时显示真实状态。恢复世代变化清除旧 Query、草稿、幂等键及事件游标，再重新载入。

验证：A-18/A-27 恢复部分/A-30；独立测试环境完整往返；损坏包不动原库；旧令牌/过期令牌拒绝；各持久切换阶段进程中断后恢复或回退；媒体缺失不假成功；重复 apply 不重复切换；恢复后旧任务不执行且旧客户端缓存失效。
