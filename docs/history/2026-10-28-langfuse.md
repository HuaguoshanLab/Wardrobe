## 首轮问题与修复

- 官方镜像代理的 worker 层下载过慢，切到官方 Docker Hub 的同版本、**相同 digest**；没有降低版本或使用第三方重打包镜像。
- Web 初始监听容器主机名，localhost 健康检查失败；显式 `HOSTNAME=0.0.0.0` 后健康通过。未移除或放宽健康检查。
- 新测试最初直接比较 SDK JSON 编码元数据，并把准备阶段/未 flush 的前一阶段 spans 混入当前断言；修正解码与测试隔离。最终全套 167 项通过，没有删除失败测试。
- 沙箱首次阻止本机网络/镜像与依赖访问；获权限后实际执行，未将受限环境失败算作服务通过。
