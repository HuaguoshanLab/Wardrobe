## 实现

- 搭配条件页增加「条件模板」：搜索、将当前五类条件另存、预览、编辑/改名、删除和明确选用。选用前对照当前条件，再次读取版本；空值也替换，不拼接旧说明。
- 城市、日期、天气、季节和单品锁定保持独立。风格 null / [] / 非空分别保留继承最新偏好、不限和明确覆盖语义；复制到草稿后仍需用户明确生成。模板更新或删除不改既有会话和历史快照。
- 后端独立表、当前用户范围、100 个有效模板限额、严格字段/词表/标签验证、版本冲突、软删除和事务回执。重复操作先读取回执，不重复创建或复活删除记录。
- 本地编辑草稿与本次条件草稿分离；未保存草稿阻止其他新建/编辑覆盖，关闭和刷新可继续。未知网络结果保留原方法、请求体和操作键，仅明确重发；确定的校验/版本失败保留输入供修正。
- 删除标签不静默改写模板；不支持字段/失效引用阻止选用，需明确修正。公共维护屏障及恢复 data_epoch 清理沿用既有机制。
- 迁移 `0013_condition_templates` 只新增表和索引。当前备份兼容标记 `0.7.7-templates`，与 `0.7.3-feedback` 精确区分；旧备份须用旧应用恢复，升级前后分别保留匹配恢复点。
- 使用 ui-ux-pro-max 定向检索和交付检查，沿用公共 Sheet、现有颜色及原生表单；无新增依赖。
