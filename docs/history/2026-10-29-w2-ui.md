# 2026-10-29 · W2 四季盘点界面与交互

用户要求修改 W2 相关 UI/UX。本轮仅修改前端展示、导航、草稿交互和相应验证；统计规则、API、数据库与 W3 范围保持原约定。

## 设计与实现

- 首屏从大段介绍改为紧凑四季切换、本季标题、编辑主入口和真实持有摘要。需求始终单列，查看结论、核对资料、修改目标的顺序更清晰。
- 新增全部/待核对/需调整/未设目标/已停用分组；数量代表需求条数，可以重叠，不伪装成去重衣服数量。分组保留 URL；手机分组栏横向滚动，生活背景移至列表后，让首张卡片的数量进入首屏。
- 卡片突出目标、结论与事实；确认有效/待核对数量可以点击进入对应明细。颜色配合图标和文字，缺口/超额用克制的暖色提示，失效规则才用错误色。
- 从卡片“修改目标”直接打开对应需求；从单品返回保留需求与核对分组。打开、切换、返回和重新核对均不发起写入或模型调用。
- 编辑页先展示需求清单，生活背景和跨季复制折叠在后；行内排序/删除按需展开，排序即时播报新位置，删除确认带需求名称。空页复制入口可直接展开复制区。
- 需求面板先填名称、大类和目标区间，细化匹配规则、备注/启用状态后置；已有规则默认展开。提供“暂不设目标”，上下限同时清空；单条应用到草稿、整季显式保存及离开保护保留。
- 子类管理增加本地名称搜索，新增时点选参考名称只填草稿；引用影响确认保留。无新依赖、无新字体或图片资产。
- 组件及样式按卡片、单品明细、编辑表单职责拆分，沿用现有暖白/深绿、Lucide、Base UI 及四项主导航。

应用 [UI/UX Pro Max](../../.agents/skills/ui-ux-pro-max/SKILL.md) 的可访问性、触控尺寸、表单渐进展开与反馈原则。`progressive disclosure` 两次本地检索只命中不相关的标题换行，未当成设计依据；展开方案依据技能内置表单原则及本项目操作顺序。React 检索命中派生状态在渲染期计算，分组不复制服务端状态。
