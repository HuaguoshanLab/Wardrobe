## 实现

- 模板列表增加总数、场合/轮换摘要、长名称换行、清空搜索和空结果说明；草稿单独展示名称与继续入口。清空搜索和放弃草稿后焦点回到搜索输入。
- 选用预览将保留的本次安排、将替换的五类条件、当前条件对照分层。超过 100 字的补充要求可展开完整内容，空备注仍明确说明会清空旧备注。
- 公共 SheetFooter 固定选用/保存操作区，短横屏压缩非必要提示，正文独立滚动；表单使用真实 form ID 提交，按钮保留校验、忙碌和失效禁用逻辑。
- 编辑区增加标题、草稿保存边界、名称字数和固定保存/返回操作。删除单独核对并提供取消；删除其他模板不再清除未保存的编辑草稿。
- 列表→预览→编辑/删除/返回具有明确焦点交接；选用后关闭弹层，将焦点交给条件页成功提示。慢网给出处理中反馈，不允许重复发送。原请求恢复结束后回到列表核对，编辑输入仍保留。
- 首轮真实浏览器发现公共弹层对已移除控件的自动焦点恢复覆盖目标焦点。按本地 Base UI 的下一帧恢复行为顺延交接，关闭后等待既有历史清理；正常动画和减少动画均补断言。
- 列表、详情与流程组合按职责拆分；无新增依赖，无后端、接口、迁移、真实模型或天气调用变化。使用 ui-ux-pro-max 定向搜索及交付检查，保持现有主题与四项导航。
