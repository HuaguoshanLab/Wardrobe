# 2026-10-30 · P7.2 界面与交互优化

用户要求优化刚交付的 P7.2 UI/UX，完整验证后部署、保留现有数据并同步记录。行为仍以 [P7.2](../P7-2.md) 为准。

## 改动

- 条件页三种模式使用一致的单选卡片：窄屏纵向、宽屏并排，单独显示“按条件 / 近 7 天 / 近 30 天”。选择后的说明与当前模式同步，明确草稿与显式生成的关系。
- 保留原生 radio 的方向键、焦点、整卡点击和禁用语义，任务中不能改选；选择和展开均不发 API 写请求。
- 轮换结果先展示简短结论：暂无记录、完整组合重复、主体重复、记录中未见相同组合、参考少穿记录；不将缺失标志或 0 天解释成“从未穿过”。
- 锁定优先/仅替换指定项始终直接可见。完整后端原文、冻结日期范围、记录总数和单品天数放进“查看轮换依据”，默认收起；切换方案时重新收起。没有删改旧快照或截断说明。
- 单品 0 天显示“期间无记录”，长名称完整换行；空记录提供日历只读入口。当前结果与历史详情复用同一组件。
- 结果改用轻量白底摘要，沿用项目森林绿和浅绿；缩减视觉占用。展开控件至少 48px、选择卡片至少 76px，焦点有轮廓与滚动避让，减少动态效果设置下取消颜色过渡。

使用项目 ui-ux-pro-max 技能。搜索“progressive disclosure”两次未命中合适的专门条目，分层展开采用技能通用表单规则与工程判断；参考其可访问性、触摸尺寸、长文本、焦点与减少动态效果检查项，未新增设计系统或外部依赖。
