# 2026-10-28 · 穿搭记录合并与界面优化

## 用户确认与完成范围

用户明确确认合并「历史与收藏」「穿搭日历」为「穿搭记录」，保留暖白、深绿和既有风格。底部及桌面主导航均改为今日穿搭、我的衣橱、穿搭记录、设置四项。`/calendar` 兼容跳转 `/collections?view=calendar`。

- 历史/收藏/日历分栏写入 URL；浏览器会话记住上次分栏、月份、选中日期及内部列表位置。历史保留连续分页缓存 30 分钟；详情返回原来源，整页刷新不承诺恢复历史全部分页。
- 历史按北京时间日期分组，整套组合图片、收藏快捷操作、记录穿着与更多面板；收藏名称默认只读，命名和取消收藏在面板完成。收藏状态读取完整分页，不把第一页之外的收藏误判为未收藏。
- 月历按周一开始，标记实际记录的日期与套数，同日多套分别展示；读取当月全部分页后才作完整标记。点击日期展示当天搭配和备注，补记入口携带选中日期，禁止未来实际穿着；月历不表示未来计划。
- 详情以固定快照组合为中心，点击单品展示当时图片/属性；天气保留快照来源，说明折叠，未拥有建议和未满足项单列。返回栏、收藏、记录穿着、以这套为基础搭配面板与其他页面统一。
- 改名、编辑穿着、取消收藏、移除历史、删除穿着记录分别说明影响。只在明确操作后写入；历史移除仍说明当前选择清空以及收藏/穿着保留。复用仅创建会话、检查当前可用性，不调用模型。
- 表单使用 React Hook Form；未修改禁用保存、脏草稿关闭和导航保护、页面刷新离开提示。失败沿用持久化幂等键与原负载重发；显式放弃待发操作后读取最新版本，保留修改字段并更新未修改字段，重新确认保存。旧待发操作命名空间兼容。
