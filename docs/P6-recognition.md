## 配置与入口

Compose 的 `RECOGNITION_MODE` 独立于搭配的 `PROVIDER_MODE`，支持 disabled/fake/qwen；Compose 默认显式 fake，纯后端缺省 disabled。

- fake：只模拟预填上装，页面标注 Fake，不发云端请求。
- disabled：保留转换、去背景和人工审核，识别步骤返回未配置。
- qwen：需后端 QWEN_BASE_URL、QWEN_API_KEY，沿用 [P4](P4.md) 的账户地域配置；仅上传照片或显式重试识别时调用。只启用搭配 qwen 不会自动启用照片 qwen。

纯后端使用 `WARDROBE_RECOGNITION_MODE`。配置改变需重新创建对应 API/worker 容器；普通查询只展示配置状态，不探测或收费。排队任务保存不含密钥的模式、模型、地址、提示版本；执行配置变化时拒绝识别，需显式重试。旧版未存识别配置的任务同样拒绝自动调用。

上传页能力状态未知或读取失败时禁止照片提交，支持重新读取；确认已配置后在操作前说明会向百炼发送标准缩略图；不发送原件或 EXIF。图像由转换结果生成最长边 1280 像素、JPEG quality=85 的请求图，经 Base64 image_url 发送。原媒体不被修改。请求关闭 thinking，要求 JSON Object，并以本地严格 schema 和词表校验，不假设服务端保证字段正确。

模型仅预填品类、名称、颜色、季节、场合、风格；不确定值为空。材质、厚度、保暖性留给人工补充，不凭外观推断；不允许输出状态、显示方式、自定义标签 ID 等控制字段。审核页展示来源和不确定性提示，用户确认后才入库。图片中的文字只能作为数据。

2026-10-27 提示更新为 garment-vision-v2：模型输出 schema 显式声明受控字段的英文代码枚举，提示区分代码与中文标签（如 top 与上装）。仍严格拒绝中文标签/非法代码，不静默转换，也不自动重试。真实调用证据见[账号验收记录](history/2026-10-27-qwen-acceptance.md)。该 schema 仅供模型输出使用，不改变公开导入接口或数据库结构。

Excel 默认不识别，已有属性保留。用户显式点击行级识别重试仍遵守只补空白/未触碰字段，不覆盖 Excel 属性。刷新、轮询、重连和打开页面不产生调用。

## 调用记录与中断

`recognition_calls` 以 job_id/row_id 为主键。发送前保存 sent、配置、图片引用和行版本，响应校验后保存 received 及响应。再次执行同一行复用已有响应；sent/unknown 没有响应时不重发。已知服务错误保留 failed 和错误码，显式新任务才可再请求。

每行最多一次 HTTP 请求、总时限 120 秒；无自动纠错、传输重试或 Fake 降级。照片批次最多 20 行、20 次请求；当前串行处理，因此最坏等待可能很长，维护屏障可能因无法在 330 秒内静止而安全失败。搭配的请求预算保持原值。

行级超时/网络结果未知记 interrupted，其他行继续；父任务结束时标 interrupted 并保存 interrupted_rows 汇总。重试新建 Job，原账本保留；界面提示可能再次计费。worker 退出靠已有租约回收，不自动重新领取旧运行任务。

响应保存与草稿合并分开：即使取消时响应已经到达，也允许保留调用证据；合并前重新校验租约、人工字段、确认/移除状态。保存响应失败按结果未知处理。模型请求期间不持有数据库写事务。

## 数据与备份升级

追加 `0006_recognition`：新增 recognition_calls，import_rows 增加 analysis_notes，旧行默认空数组；旧迁移不修改。原有搭配调用账本、不可变快照和媒体保持。

备份仍是数据格式 v1，但精确兼容标识更新为 app_version=0.1.0-p6、Alembic revision=0006_recognition。新版完整备份包含识别账本和提示。P5 的旧包和恢复点仍保留，但新版不直接恢复它们；需要在匹配旧版本的隔离环境恢复后迁移，当前没有自动跨版本转换功能。切勿删除旧包或将旧数据库直接连接新版服务而不迁移。

新增能力字段 recognition（fake/configured/unconfigured）、行字段 analysis_notes、导入汇总 interrupted_rows。旧 Job 结果缺少 interrupted_rows 时按 0 读取。恢复仍转旧活动任务为 interrupted，账本不自动重发。

## 验证限制

模拟 HTTP 能证明请求结构、字段校验、错误和重试边界；真实 PostgreSQL 能验证账本、人工优先、取消和备份恢复。它们不能证明真实账号可用、识别质量、实际费用或真机体验。真实账号需少量已获允许的照片逐项核对，按 P6 验收计划记录；本轮不发真实模型请求。
