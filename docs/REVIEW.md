日期：2026-10-26。范围：P0 时原有 11 份 Markdown；当时新增此审查索引。以下是 P0 审查快照，当时没有应用实现；后续 P1 已完成，当前工程事实见 [P1](P1.md) 和 [DEVELOPMENT](DEVELOPMENT.md)，不要把历史审查状态当作当前状态。

## 1. 发现与修正

| 问题 | 后果 | 本次修正位置 |
|---|---|---|
| 只写锁定规则，未界定“只换一件” | AI 可能把未锁定的整套都换掉 | CONTRACTS 的 scope；A-23；D-20 |
| 缺少当前会话、选择与消息恢复协议 | 刷新丢锁定、聊天上下文，前端自行重生成 | 会话/消息接口、current 指针、A-25 |
| AI 异步预填没有人工字段优先级 | 晚到结果覆盖用户修改，甚至覆盖已确认数据 | touched_fields、版本检查、A-24；D-21 |
| 批量确认缺少部分成功和重试语义 | 一行错误阻塞整批，重试重复入库 | 逐行事务/幂等、稳定 Job 终态、A-26 |
| 通用 result 只描述搭配 revision | 导入和备份被迫伪造结果结构 | 按 kind 区分结果、A-27 |
| SSE 没有终态关闭与事件过期边界 | 终态仍重连，旧游标无法恢复 | 终态补发关闭、7 天事件默认保留、查询恢复 |
| 检查点、任务、结果事务边界不完整 | 崩溃重放重复调用模型或重复保存 | outbox/租约、步骤响应、原子业务提交、A-28；D-22 |
| 取消、重试和模型预算不够明确 | 取消后仍提交，后台无限重试或隐式重复付费 | 终态竞争、显式新 Job、总预算、A-29/A-31 |
| 备份只谈数据库与文件，未冻结 worker | 文件与记录不一致，恢复后状态丢失 | 全局静止、独立控制记录、成对回退、A-30；D-23 |
| A-18 “无凭据泄露、旧任务自动执行”有歧义 | 被理解成恢复后自动跑任务 | 明确不泄露凭据且不自动执行旧任务 |
| 天气、能力、历史删除边界遗漏 | 0℃被当空值、串城市、假服务成功、收藏图片失效 | 天气快照/能力接口/隐藏语义、A-32 至 A-34；D-24 |
| 通用 JSON 与媒体/SSE、P1 与后续 schema 范围混淆 | 前后端各自解释，P1 堆空 API | 二进制例外、统一路径、按阶段补 schema；D-25 |

新增默认均标记为“设计基线”，没有把调整默认一套、事件保留期等冒充用户明确选择。没有新增账号、商城、自动记忆或其他产品范围。

## 3. 实现前仍需完成的门槛

| 阶段 | 必须补齐/验证 | 未完成时不得声称 |
|---|---|---|
| P1 | 精确版本及构建；队列选型；事务/租约/取消；检查点恢复；OpenAPI 生成和通用 schema | 工程已能启动、任务可靠、自动检查已生效 |
| P2 | 品类/属性完整词表；真实 Excel 往返；HEIC 方向与解码；rembg 构建和效果；人工字段合并 | 所有 Excel 图片都兼容、所有手机照片都已支持 |
| P3 | 偏好字段与取值；和风地域/认证/城市天气；手动降级 | 真实天气联调完成 |
| P4 | 百炼地域与结构化输出能力；步骤预算；真实调用及故障恢复；按钮/聊天一致 | Fake 通过等于真实模型通过，或模型请求恰好一次 |
| P5 | 备份清单格式与大小限制；兼容版本；控制状态重启恢复；损坏包、空间不足和切换失败回退 | 跨数据库和文件系统天然原子、备份有文件就能恢复 |
| P6 | 目标手机真机流程、全量场景、升级迁移及运行说明 | 浏览器模拟等于 iOS/安卓真机验收 |

详细字段在各阶段**实现之前**写成可执行 schema 并同步契约；不能让前后端分别临时猜测。未完成的凭据或平台验证只阻塞对应能力的真实验收，不阻塞手工/Fake 流程开发。
