# P7.7 · 常用搭配条件模板

范围依据 PRODUCT P-37 与 [P7 计划](plans/P7-advanced.md)。模板只管理可复用条件，不自动生成，也不是长期偏好。实施和部署证据见 [DEVELOPMENT](DEVELOPMENT.md)。

## 产品行为

- 「搭配条件 → 条件模板」查看、搜索、另存当前条件、编辑/改名及确认删除。每个模板为独立记录，最多 100 个未删除模板，名称去首尾空白后 1～60 字；允许同名，以独立 ID 区分。
- 仅保存 `occasion_codes`、`style_codes`、`custom_tag_ids`、`notes`、`rotation_mode`。不保存城市、日期、天气、手动温度、季节、具体单品锁定、会话或穿着记录。
- 风格 `null` 表示生成时继承最新长期偏好，`[]` 明确本次不限，非空数组明确覆盖。模板不复制偏好；本次 notes 替换本次 notes，不拼接旧说明，长期偏好 notes 保持独立。
- 选用前展示模板内容、可展开的当前条件以及保留的当前城市/日期/锁定数量；始终明确确认替换五类字段，空值也覆盖。其他条件和单品锁定保持；选用后展开天气区域供本次核对，城市切换沿用原草稿迁移和天气清理，生成端重新校验天气时效。
- 选用只复制到当前草稿；可以继续修改，点击生成才提交。生成、会话和不可变结果沿用现有条件快照，不依赖模板最新值。修改或删除模板不改变已提交会话、历史结果或已填草稿。
- 标签删除不自动改写模板。读取模板时标明失效标签或不支持字段；禁止直接选用。编辑时必须明确移除失效条件；无法解析的旧结构需明确采用下方当前条件修正，不能悄悄丢字段。
- 模板编辑草稿独立存于本浏览器，关闭和刷新后可继续；有旧草稿时先继续或明确放弃，不能由新建覆盖。版本冲突保留输入，用户可读取最新版本后明确再次保存。
- 网络结果不明确时保存原方法、路径、请求体和操作键；刷新不自动发送。可明确重发原操作，或成功读取列表后结束恢复并核对结果。恢复 data_epoch 变化沿用公共机制清除草稿、待发操作和缓存。

界面细化与焦点、长文本、固定操作栏验收见 [P7.7 UI/UX 记录](history/2026-11-04-p7-7-ui.md)。

## API

所有路径位于 `/api/v1/condition-templates`。写接口均要求 8～128 字 `Idempotency-Key`；GET 和模板操作本身零模型任务。

| 方法/路径 | 输入与结果 |
|---|---|
| GET 集合 | 当前用户未删除模板列表，创建时间倒序、ID 次序；最多 100 个 |
| GET `/{id}` | 当前记录；不存在/删除返回 404 |
| POST 集合 | `{name,conditions}`，201 返回 TemplateView |
| PATCH `/{id}` | `{expected_version,name,conditions}`，完整替换名称和模板字段，版本递增 |
| DELETE `/{id}` | JSON `{expected_version}`，返回 `{id,version,deleted:true}`；软删除并递增版本 |

TemplateView 包含 `id,name,conditions,version,created_at,updated_at,issues`。conditions 读取为 JSON，以便旧字段问题可见；写入为严格 TemplateConditions，字段外输入和未知词表明确 422。失效标签保存也返回 422；版本不一致和同键不同内容返回 409。

场合/风格各最多 8 项、标签最多 30 项、补充说明最多 1000 字；轮换为 normal/avoid_recent/less_worn。模板清单不代替标签词表。前端显示后、确认选用前再次 GET 核对版本和问题；变化时留在预览让用户重新确认。

## 持久化与兼容

- 新表 `condition_templates`：独立 UUID、owner_id、name、conditions JSONB、version、created_at、updated_at、deleted_at；按 owner/删除状态索引。
- 迁移 `0013_condition_templates` 为新增表和索引，不改旧行；有任何模板记录时拒绝直接 downgrade，避免丢失记录。未使用的新表可撤销迁移；回退必须与匹配版本备份一起规划。
- 创建限额采用事务锁；更新/删除采用行锁和 expected_version。操作回执先于版本/存在检查，旧请求重放返回旧回执，不重复创建、不复活删除项、不覆盖后续修改。标签校验持有与删除冲突的表共享锁。
- 维护屏障覆盖新接口；备份通过完整模型注册表包含模板、删除标记及既有操作回执。
- 备份兼容标记更新为 `0.7.7-templates` / `0013_condition_templates`，继续精确版本校验。旧 `0.7.3-feedback` 备份由旧应用恢复，不能直接导入新应用；保留升级前旧镜像和完整备份，升级后生成新版本备份。
