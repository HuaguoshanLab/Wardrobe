# D-29 · P4 任务与不可变结果

日期：2026-10-26。工程实现；真实云端效果待验。

- 保留 P1 PostgreSQL Job 队列和租约，在 P4 使用同一取消/SSE/重试入口。LangGraph 三节点读取上下文、调用及校验、提交结果；会话映射稳定 thread_id。
- 模型发送前落库，响应落库后进入提交；调用结果不明中断，明确重试产生新 Job。用业务提交标记和唯一约束保证不重复持久化，不声称外部请求恰好一次。
- outfit_images 固定原媒体外键及实际存储键；revision JSON 引用该不可变图片 ID。图片字节复用，未来垃圾回收必须检查这些引用。
- 首版候选最多 500 件，超限明确失败；不静默截断候选。后续大衣橱需求出现时再增加可解释候选检索。
- 千问采用 JSON Object、关闭 thinking、本地 schema 与业务约束；不自动 HTTP 重试，不依赖模型自行遵守锁定。模型固定 qwen3-vl-plus，地域地址由用户账户配置。
- 首版搭配模型输入为已审核属性及条件；照片视觉识别仍为 P2 Fake/手工范围。真实账号未验，不能用模拟成功代替。
- 活动请求期间禁止修改会话；聊天只解析为有限操作，不拥有衣橱写入权限。UI 显式重发网络失败请求，刷新只有查询。
