# D-33 · 可选 Langfuse 观测

2026-10-28，用户确认实施。范围为独立本地部署、两条模型调用链、用量统计及故障隔离。

## 决策

- Python SDK 5.0.4 与服务端 4.71.0 配套锁定；应用技术栈和既有模型保持。
- Langfuse 在独立 Compose 项目/存储中运行，应用不等待其健康，配置只授予 worker。
- HTTPX 适配器和业务步骤显式埋点，不通过自动回调采集图参数或照片。根 Trace 关联现有 Job，不新增业务运行 ID、业务表或迁移。
- 保留原调用账本、幂等、租约、调用预算及有限纠错；观测可丢失，不参与恢复决策。
- 默认摘要采集，正文调试显式开启；不捕获照片、秘密或自动异常堆栈。2026-10-29 根据用户反馈，将开启采集后的搭配 Input 从单独 message 改为明确标记的白名单输入摘要，覆盖无聊天文本的按钮生成；仍不采集完整衣橱快照、精确定位或系统提示词。
- 采用有日期和地域范围的人民币价格估算；美元字段只在明确换算率后写入。

## 取舍与复查

手工埋点需随工作流维护，但可以控制语义和数据范围。独立观测栈有额外内存、存储和运维成本。进程强杀后可能缺少结束事件；不为补齐遥测增加业务级 outbox 或重放模型请求。

升级服务端/SDK、开放远程管理、扩大采集范围或加入评测时复查。运行方式和边界以 [LANGFUSE](../LANGFUSE.md) 为准，验证见 [本轮记录](../history/2026-10-28-langfuse.md)。
