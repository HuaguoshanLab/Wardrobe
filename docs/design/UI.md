## 视觉与组件

异常内容：公共弹窗标题允许长词换行，关闭按钮保持至少 44px；今日穿搭及单品详情的空图片/加载失败均展示明确占位。天气气泡保持圆形与原有布局，未知温度使用紧凑字号，长天气单行省略，完整天气保留在“搭配说明”中。验证见 [异常内容修复](../history/2026-10-28-mobile-content-fixes.md)。

整体风格：温润极简的衣橱画册。真实衣服为主角，保留暖白和深绿，减少装饰容器与工程术语；展示页重视觉，管理页重效率。

穿搭记录：底部导航统一四项，历史/收藏/日历作为同一页面的分栏。历史按北京时间日期分组，以整套组合图片为主体；收藏名称默认只读，改名/取消收藏通过面板完成。月历按整月完整分页数据标记实际穿着，点选日期展示多套记录，补记携带选中日期。查看详情保留来源分栏、月份、日期和列表位置；详情采用公共返回栏、组合展示、单品快照面板和折叠说明。编辑离开保护、失败原操作重发和显式读取新版本保留草稿。旧 `/calendar` 兼容跳转。证据见 [穿搭记录改造](../history/2026-10-28-records-refinement.md)。

- 暖白背景 `#f7f7f2`、白色表面、深绿主操作 `#294f40`、正文 `#273b32`、次级文字 `#626d65`；错误色 `#a3312c`。全局语义变量在 `frontend/src/app/shell.css`。
- 保留中文系统字体，不依赖外部字体服务。正文基准 16px，说明 14px，辅助信息 12px；小号字仅品牌英文、眉题和底部导航。
- 页面标题 28–36px；卡片圆角 16–18px；常用间距 8/12/16/20/24/32px；主要控件至少 44px 高。
- 延续 Lucide 图标；有文字的装饰图标不重复朗读。按钮有 hover、pressed、disabled、focus 状态；遵循 reduced-motion。
- 760px 以下固定底部四项导航，保留安全区和正文底部空间；更宽屏幕使用侧栏。详细页和录入页保持所属导航选中。
- 衣橱样式与导入/审核样式分开维护；搭配卡片样式由收藏页显式加载，直接打开页面也必须一致。

## 信息与交互

- 首页及 `/outfits/:sessionId` 采用图片优先的单套展示；一次显示一套，方案按钮切换本地预览。只有点击“选用这套”才保存服务端选择，浏览/刷新不生成。
- 手机首屏展示真实衣服图片，未拥有建议单独以文字呈现；不得补造衣服或模特图。显示结果保存日期，避免把旧结果冒充今日新生成。
- `/outfits/prepare` 与 `/outfits/:sessionId/prepare` 承载条件；天气与城市摘要置顶，展开可查看详情与手动覆盖，场合和补充要求常驻，风格/季节/标签折叠。草稿自动保存在本浏览器；“核对条件”是辅助动作。提交获得明确生成任务响应后返回对应结果页，未确认请求仍保留原幂等键，打开子页不提交。
- “调整这套”在当前穿搭页打开底部面板，按“单品调整 / 描述要求”分组，前者包括锁定、局部替换与重搭，后者包括聊天与消息记录。提交获得明确响应后关闭面板展示任务进度；失败保留面板与输入，原操作可显式重发。复用当前页面控制器与会话版本；查询参数 `adjust=1` 恢复面板打开状态，不生成。旧 `/outfits/:sessionId/edit` 重定向到对应穿搭页并打开面板。
- 用户确认保留现有背景；2026-10-28 用户明确偏好单列，替换双列拼版：真实衣服按上装/外套/裙装/下装/鞋/配饰顺序纵向排列，去掉单件卡片与放大装饰，锁定标记保留。收藏、记录穿着、搭配说明在右侧带文字工具栏中，保存反馈与待发重试在全宽区域显示；重新搭配和选用/调整也收进侧栏下半部，以分隔线分组，选用/调整保留深绿主按钮，取消底部操作栏。天气、单列衣服与工具栏在同一网格中顶部对齐，以横向间距防遮挡；生成时天气为衣服区左上方透明皂膜气泡（低色散、无彩虹炫光、柔和亮边、半透明内部及两颗错落小泡），去掉厚重玻璃内阴影，保留生成时标识、温度及天气，说明按依据/提醒/审美分区，完整属性折叠保留。收藏和记录穿着使用独立短面板，在当前页完成并反馈，不跳往历史详情；选用仍不等于穿过。
- 今日穿搭顶部不再重复展示“搭配条件”，已有搭配仅通过“重新搭配”进入条件页；没有搭配时保留“准备搭配”空状态入口。
- 横向滑动和方案按钮均可只读预览，纵向滚动不切换。单品与说明使用公共 Base UI 底部面板，固定标题/关闭入口，正文独立滚动，移除没有手势行为的拖动把手；支持关闭、Escape、焦点恢复；点击单品仅查看快照，明确替换复用原 replace_items 操作。单品面板展示保存时属性，未标注保持未知；选用后可在面板内锁定/解锁。锁定或未选用方案中的单品不能直接替换。失效提示保留，未满足项计数可见。验证见 [展示台记录](../history/2026-10-27-outfit-stage.md)。
- 手机移除重复顶栏标语和页脚；保留四项底部导航与安全区。子页有明确返回入口，路由滚动位置通过 React Router ScrollRestoration 管理。
- 衣橱采用左侧固定品类、顶部固定季节，衣服列表和品类栏各自滚动；保留双列图片及现有背景。搜索常驻，场合/状态/标签收进“筛选”底部面板，即时应用并显示额外条件数量。
- 衣橱筛选写入 URL，搜索防抖，条件可逐项移除；更多筛选独立重置。列表连续加载并显示已加载数量，同一应用会话内详情返回保留已加载页和滚动位置（缓存保留 30 分钟）；切换条件回到顶部。筛选无结果与真正空衣橱区分，加载骨架、失败重试和清除筛选都有实际行为。
- 单品详情默认查看大图、名称/状态、档案摘要，使用公共返回标题栏。预览原图/去背景不写入，默认展示图单独保存；编辑按信息分组、多选按钮化，仅保存修改字段，离开保护与版本冲突保留草稿。删除、标签新增/改名/删除使用公共面板，标签管理位于衣橱顶部。实现证据见 [衣橱优化记录](../history/2026-10-28-wardrobe-refinement.md)。
- 录入区显示“选择文件 → 检查与修改 → 确认入库”，不暗示上传即入库。照片以缩略图网格预览、逐项添加/移除；Excel 模板下载常驻，图片规则折叠配示意。审核采用状态摘要、筛选、图片与品类优先的表格/手机卡片；处理明细折叠，底部保留批量操作。属性编辑、图片、移除/重试和入库确认统一面板，编辑保护与原请求恢复清楚区分。实现证据见 [录入流程优化](../history/2026-10-28-imports-refinement.md)。
- 设置首页保留四行入口，按个人偏好、数据与服务分组，显示当前偏好/城市摘要。子页统一返回栏；偏好分组、颜色带色点与文字、底部粘性保存区及离开确认。城市突出当前值，手填折叠、清空用确认面板；从搭配条件进入时返回原条件页并保留非天气草稿。备份与恢复分区，覆盖前用统一面板显示摘要并确认；服务逐项展示配置，诊断折叠。加载、读取失败和未配置分别表达。证据见 [设置优化](../history/2026-10-28-settings-refinement.md)。
- 搭配条件和录入衣服也使用相同的公共 PageHeader；前者返回对应会话穿搭（无会话路径则返回首页），后者返回衣橱。移除这两页原先分离的返回文本和大标题，保留原表单、提示及录入步骤。

首轮证据见 [开发记录](../history/2026-10-27-ui-refresh.md)，H5 图片优先改造见 [后续记录](../history/2026-10-27-h5-lookbook.md)。这些是工程设计默认，不新增产品能力。
